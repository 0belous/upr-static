# Archive Repo
This repository contains pre-generated manifests for those running on declerative operating systems.
Choose the manifest corresponding to your jellyfin version, if you do not see your version run this command:
```
curl https://obelo.us/upr -H "User-Agent: jellyfin/12.0.0"
```
Replacing 12.0.0 with your jellyfin version, a manifest should appear soon.
